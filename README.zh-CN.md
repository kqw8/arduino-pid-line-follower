# Arduino PID 巡线机器人

两份经过实车测试的 Arduino 巡线程序，针对直线和急弯自适应调整转向，附实用 PID 教程。

## 选择程序

| 程序 | 方案 |
| --- | --- |
| [Dynamic PID](dynamic_pid/dynamic_pid.ino) | 连续调整增益：中心附近柔和，边缘更强。 |
| [Two-Mode PID](two_mode_pid/two_mode_pid.ino) | 在 CRUISE 与 TURN 参数间切换，带消抖和最短停留时间。 |

两者都包含传感器校准、微分滤波、积分限幅和弯道减速。

## 运行

已测试硬件：Arduino Mega 2560、两个 TT 减速电机、Adafruit Motor Shield 和七个光敏电阻。

1. 在 Arduino IDE 中打开上面任一 `.ino` 程序。
2. 通过库管理器安装 **Adafruit Motor Shield V2 Library** 及其依赖。
3. 选择开发板和端口，按接线修改硬件常量：
   默认传感器从左到右接 A8–A14，电机接扩展板端口 1 和 2。
4. 上传后将整个传感器阵列先放白色表面，再放黑色表面校准。
   LED 闪烁表示定位阶段，常亮表示采样，此时保持静止。
5. 校准后机器人会开始行驶。先低速检查电机方向。

其他开发板需要兼容的引脚和硬件；更换驱动器需要修改电机控制代码。

## 限制与调参

- 校准假定黑色读数高于白色，不会识别反向极性。
- 轮子指令是 PWM 而非实测轮速，限制在 0–`MAX_WHEEL`，不倒转或原地旋转。
- 丢线后无限期保持上次位置，**没有丢线超时停车功能**。
- 200 Hz 是目标频率，不是实时保证；参数需要针对实际机器人和赛道调整。
- 每次只改一个参数：从低速开始，先调 `KP`，再调 `KD`，`KI` 通常保持 0。
