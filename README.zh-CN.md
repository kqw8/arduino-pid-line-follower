# Arduino PID 巡线机器人：两种控制方案

这份教程面向正在学习 PID 巡线机器人的读者。巡线是自动驾驶控制的经典入门问题，这里介绍两种超越固定参数 PID 的方案及其调参方法。两种方案都已在作者的实物机器人上测试。

## PID 基础

机器人前方横向排列一组光敏传感器，用来估计黑线相对阵列中心的 **position**。中心为零，线在右侧时为正，在左侧时为负；这个偏离中心的位置就是 **error**。弯道、左右轮差异和惯性都会让误差不断变化。

PID 把误差转成左右轮的速度差：

- **P（比例）**：误差越大，转向越强；负责主要响应，但过强容易越过中心、来回摆动。
- **I（积分）**：累积持续存在的误差，用于消除长期偏向一侧的小偏差。巡线通常不需要很强的积分。
- **D（微分）**：根据误差变化率提供阻尼，回到黑线时提前减小纠正，减少过冲。若 P 像弹簧，D 就像减振器。

```text
correction = KP * error + KI * integral + KD * derivative
left wheel  = speed + correction
right wheel = speed - correction
```

`KP`、`KI`、`KD` 需要针对实际机器人和赛道调整。

## 固定参数 PID 的局限

赛道同时包含直线、缓弯和急弯。适合急弯的强转向可能让直线摆动，适合直线的柔和转向可能在急弯跟不上。折中参数往往需要降低速度。固定参数在某些赛道上也能表现很好，但自适应响应有助于兼顾直线稳定和急弯转向。

## 硬件与运行

作者使用 Arduino Mega 2560、两个 TT 减速电机、Adafruit Motor Shield，以及前方横向排列的七个光敏电阻。本教程侧重算法和调参，不是机械搭建指南。

仓库提供两个可独立使用的 C++ `.ino` 程序：

- [Dynamic PID](dynamic_pid/dynamic_pid.ino)
- [Two-Mode PID](two_mode_pid/two_mode_pid.ino)

在 Arduino IDE 中打开其中一个，通过库管理器安装 **Adafruit Motor Shield V2 Library** 及其依赖，然后选择开发板和端口。程序使用 `Wire.h` 和 `Adafruit_MotorShield.h`。上传前按接线修改硬件常量：默认七个传感器从左到右接 A8–A14，左右电机分别接扩展板端口 1 和 2。其他开发板需要兼容的引脚和硬件；更换电机驱动器需要修改电机控制代码。

启动时先将整个传感器阵列放在白色表面，再放在黑色表面。LED 闪烁表示可以移动，常亮表示正在采样，需要保持静止。每阶段预留 2000 ms 定位，每个传感器平均采样 200 次。校准假定黑色的模拟读数高于白色；代码会强制至少 20 个计数的差值，不会自动识别反向极性。

校准完成后机器人会开始行驶，先低速检查电机方向。轮子指令是 PWM 数值，不是实测轮速。两个控制循环都将轮子指令限制在 0–`MAX_WHEEL`，不会主动倒转或原地旋转。丢线后会无限期保持上次位置，没有丢线超时停车功能。

## 两种方案共同的改进

两份程序共享硬件、传感器处理、校准、循环框架和电机代码，区别主要在转向策略。

### 信号质量

1. **逐传感器校准与归一化。** 不同传感器对白色、黑色和环境光的响应不同。启动时分别测量，再用 `map()` 映射到白色为 0、黑色为 1000 的统一尺度，减少传感器差异造成的偏差。
2. **死区去噪。** 白色表面的读数也会波动。低于 `SENSOR_DEADBAND` 的读数置零，避免噪声参与位置计算，尤其是外侧传感器权重较大时。
3. **加权平均位置。** 只取最暗传感器会得到跳变的整数位置；使用 `position = Σ(value × weight) / Σ(value)`，可以得到如 1.5 的连续位置，让转向更平滑。外侧权重也可用于增强边缘响应。

### PID 本身

4. **微分低通滤波。** 微分为 `(error − lastError) / DT`，差分和较小的时间间隔会放大噪声。指数平滑 `dFiltered = α × new + (1 − α) × old` 可抑制尖峰，同时保留变化趋势。较小的 `D_SMOOTHING` 更平滑，但延迟更大。
5. **积分限幅。** 持续偏离或短暂丢线会积累积分，重新回线后仍可能继续推动转向，造成延迟过冲。将积分限制在 ±`INTEGRAL_LIMIT`，避免无限累积。

### 行为与稳健性

6. **弯道自动减速。** 基础关系为 `speed = base − slowFactor × |error|`，并限制在最低与最高速度之间。误差越大越慢，直线则接近最高速度。减速可以降低转弯所需的向心力，并增加响应时间。
7. **丢线保持最后位置。** 总信号低于 `LINE_LOST_LEVEL` 时返回最后一次有效位置，而不是误认为位置为零并直行。这样通常能继续朝最后见到黑线的一侧转向，但不保证重新捕获黑线。
8. **目标 200 Hz 的循环门控。** 距离上次更新不足 `LOOP_US` 就跳过，并用固定 `DT` 计算微分和积分。200 Hz 对应假定的 5 ms 间隔，但这不是实时保证：传感器读取和电机通信可能拖慢循环，导致真实间隔与 `DT` 不一致，影响增益的实际效果。

### 使用便利性

9. **每次启动重新校准。** 适应赛道和光照变化，通过多次采样平均减小噪声；LED 提示先白后黑的两个阶段。
10. **电机方向标志。** `LEFT_MOTOR_REVERSED`、`RIGHT_MOTOR_REVERSED` 可在软件中反转单个电机方向。单轮方向错误可能导致原地打转，整车后退则应检查两轮方向。

## 方案一：Dynamic PID

目标是在直线轻柔转向，在急弯加强转向，通过连续曲线调整 P 项：

```text
shape(pos) = pos * (STEER_SOFTNESS + (1 - STEER_SOFTNESS) * (pos / MAX_POSITION)^2)
correction = KP * shape(position) + KI * integral + KD * dFiltered
```

中心附近的乘数约为 `STEER_SOFTNESS`，纠正较柔和；靠近边缘时乘数接近 1，转向更强。结合自动减速，就能用单一连续循环兼顾直线和弯道，无需切换模式。

## 方案二：Two-Mode PID

使用普通线性 PID，但准备两套完整参数：

- **CRUISE**：较快、转向较柔和，用于直线和缓弯。
- **TURN**：较慢、转向更强、随误差减速更明显，用于急弯。

状态机根据误差绝对值切换。连续若干循环高于进入阈值才进入 TURN，连续若干循环低于退出阈值才回到 CRUISE，避免噪声造成反复切换。`MIN_TURN_MS` 还规定 TURN 的最短停留时间，避免在连续急弯中途切回巡航。

第一种方案通过连续曲线适应赛道，第二种通过两套固定参数切换；比较这两种思路是本仓库的重点。

## 参数与调参

### 共同参数

| 参数 | 作用 |
| --- | --- |
| `SENSOR_PINS`、`NUM_SENSORS` | 从左到右的模拟传感器引脚和数量 |
| `MOTOR_LEFT_PORT`、`MOTOR_RIGHT_PORT` | 左右电机的 Adafruit 扩展板端口 |
| `LEFT_MOTOR_REVERSED`、`RIGHT_MOTOR_REVERSED` | 反转对应电机方向 |
| `SENSOR_WEIGHTS` | 各传感器位置权重，增大两端权重可增强边缘响应 |
| `MAX_POSITION` | 位置限幅与动态转向归一化范围，默认 3.0 |
| `SENSOR_DEADBAND` | 低于该值的归一化读数视为白色或噪声 |
| `LINE_LOST_LEVEL` | 总信号低于该值视为丢线 |
| `D_SMOOTHING` | 微分低通系数，0–1；越小越平滑，延迟越大 |
| `INTEGRAL_LIMIT` | 积分限幅 |
| `MAX_WHEEL` | 单轮 PWM 上限 |
| `LOOP_HZ` | 目标控制频率，200 Hz |
| `CALIB_READS`、`CALIB_POSITION_MS` | 校准采样次数、定位等待时间 |

### Dynamic PID 参数

| 参数 | 作用 |
| --- | --- |
| `TOP_SPEED` | 直线速度 |
| `MIN_SPEED` | 弯道最低速度 |
| `SLOW_FACTOR` | 随误差增大而减速的强度 |
| `KP` | 转向强度 |
| `KI` | 积分增益，通常保持 0 |
| `KD` | 阻尼，摆动时可适当增加 |
| `STEER_SOFTNESS` | 小于 1 时中心柔和、边缘更强；为 1 时是线性 P 项 |

### Two-Mode PID 参数

| 参数 | 作用 |
| --- | --- |
| `CRUISE` / `TURN` | 各模式的 `{ baseSpeed, minSpeed, KP, KI, KD, slowFactor }` |
| `ENTER_TURN_ERROR` | 持续高于该误差绝对值时进入 TURN |
| `EXIT_TURN_ERROR` | 持续低于该误差绝对值时回到 CRUISE |
| `ENTER_TURN_COUNT` | 确认进入弯道所需的连续循环次数 |
| `EXIT_TURN_COUNT` | 确认离开弯道所需的连续循环次数 |
| `MIN_TURN_MS` | TURN 最短停留时间 |

### 推荐调参顺序

每次只改一个参数：

1. 先低速实现稳定巡线，再提高速度。
2. 调 `KP`：太低会转向不足、偏出弯道，太高会摆动。
3. 调 `KD` 抑制摆动；若出现抖动，再用 `D_SMOOTHING` 平滑。
4. `KI` 保持 0，除非机器人长期偏向一侧、始终无法居中。
5. Dynamic PID 用 `SLOW_FACTOR` 调弯道减速，用 `STEER_SOFTNESS`（可从约 0.3–0.5 开始）调整转向曲线。Two-Mode PID 分别在直线调 CRUISE、急弯调 TURN，再调整阈值和 `MIN_TURN_MS`，确保在困难路段及时切换并保持。

## 进一步学习：正式调参方法

上面采用实车手调，也可以学习控制理论中的正式方法：

- **频域环路整形与 Bode 图**：建立数学模型，分析频率响应，再按目标稳定裕度设计控制器。这涉及较完整的控制课程知识。参见 [LibreTexts 的 Bode 图 PID 调参介绍](https://eng.libretexts.org/Bookshelves/Industrial_and_Systems_Engineering/Chemical_Process_Dynamics_and_Controls_(Woolf)/09%3A_Proportional-Integral-Derivative_(PID)_Control/9.04%3A_PID_tuning_via_Frequency_Responses_with_Bode_Plots)。
- **Ziegler–Nichols 方法**：逐步增大 P，直到出现持续振荡，再根据振荡周期等信息按表选取参数。参见 [Wikipedia 介绍](https://en.wikipedia.org/wiki/Ziegler%E2%80%93Nichols_method)。

这些链接供进一步学习。对小型机器人，基于模型的方法可能比实际需要更复杂；廉价传感器、柔性底盘和不匹配的电机会降低模型准确性。多数情况下，直接针对实际赛道调参更快。

## 另一种思路：增大外侧传感器权重

也可以不改变 P 项曲线，而在位置计算中增大外侧传感器权重。黑线接近边缘时，加权平均会产生更大的位置值，普通线性 PID 就会给出更强的纠正。

它与 Dynamic PID 的目标相同，差别在于非线性的位置：Dynamic PID 保持默认 −3 到 +3 的位置尺度，在控制器中改变响应；外侧加权则先改变测量映射，再使用线性 PID。后一种方式只需调整权重数组，结构很简单。

代价是边缘噪声也会被放大。外侧传感器的轻微校准误差、环境光干扰，以及底盘弯曲或倾斜，都可能让加权位置大幅变化，造成不必要的强转向。

两份程序都把位置限制在 ±`MAX_POSITION`，默认 3.0。因此只增大外侧权重会更早达到限幅，而不会无限增大位置。尝试时需要一起考虑限幅、增益，以及 Dynamic PID 的归一化范围。

传感器稳定、底盘刚性好时，这是一种简洁的增强弯道响应方法。硬件较粗糙时，保留测量尺度、在控制器中调整响应通常更稳妥。作者因此没有继续采用外侧加权，但它仍值得在合适的硬件上尝试。
